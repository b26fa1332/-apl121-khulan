## Өөрийн тогтоосон дүрмүүд

| Оноо | Үсэг | Голчийн оноо |
|---|---|---|
| 90-100 | A | 4.0 |
| 80-89 | B | 3.0 |
| 70-79 | C | 2.0 |
| 60-69 | D | 1.0 |
| 0-59 | F | 0.0 |

- Хичээлийн тоо: 5-аас 10
- Оноо: 0-аас 100
- Кредит: 1-ээс 6
- Голч = Σ(голчийн оноо × кредит) / Σ кредит
- Буруу утга орвол do-while-аар дахин асууна
